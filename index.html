Konfiguration mangler

Supabase-URL og anon key blev ikke fundet. De læses fra miljøvariablerne VITE_SUPABASE_URL og VITE_SUPABASE_ANON_KEY. Lokalt:

cp .env.example .env   # udfyld værdierne
npm run dev

På Vercel sættes de to variabler under Project Settings → Environment Variables. Kør også supabase/setup.sql i Supabase' SQL Editor, så tabellerne findes.
