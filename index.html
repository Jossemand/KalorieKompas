Konfiguration mangler

Supabase-URL og anon key blev ikke fundet. De læses fra miljøvariablerne VITE_SUPABASE_URL og VITE_SUPABASE_ANON_KEY. Lokalt:

cp .env.example .env # udfyld værdierne npm run dev

På Vercel sættes de to variabler under Project Settings → Environment Variables. Værdierne findes under Project Settings → API Keys i Supabase. Kør også supabase/setup.sql i SQL-editoren, så tabellerne findes.
